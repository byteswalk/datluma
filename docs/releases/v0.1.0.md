DBLENS（数洞）首个预览版。

- 数据库：MySQL / MariaDB、PostgreSQL、Oracle（11.2、19c、23ai）、达梦、SQL Server、SQLite，以及 TiDB、OceanBase（含 Oracle 模式）、openGauss、GaussDB、人大金仓、GoldenDB、GBase 8s。
- 查询工作台：对象树、SQL 编辑器（高亮、补全、格式化）、多语句执行与取消、事务、结果导出、历史与收藏。
- 数据：表数据编辑，CSV、Excel、SQL 文件的导入和导出。
- 结构：表设计器、模型文件、结构比对与同步、ER 图、数据字典和设计文档导出。
- 迁移：库到库的结构和数据迁移，支持断点续传和校验。
- GBase 8s：除修改账号外的全部功能，包括表设计器、导入、比对、模型、迁移和规范检查，账号与权限可查看。
- 账号与权限：查看用户、角色、实际权限和“谁能访问”，建用户、改密、锁定、授予和回收，所有修改先预览。生产连接上的 GRANT、REVOKE、CREATE USER、ALTER USER 要确认。
- 规范检查：按规范库检查库或模型，Word、Excel 报告，人工结论和例外。
- AI 辅助（可选）：接入 OpenAI 兼容接口（DeepSeek、通义、Ollama 等）、Anthropic，或本机智能体命令行。生成 SQL（Ctrl+I）、解释、优化建议、报错修复、补注释、规范问题建议、迁移对象转换。默认只发表结构，不发数据；结果只是建议，不会自动执行。
- MCP：把打开了 MCP 访问的连接以只读工具交给本机智能体（Claude Code、Codex、Cursor 等），配置片段在“设置 → AI”。
- 形态：桌面程序（Windows、macOS、Linux）和浏览器模式，支持自动更新。

安装：

- Windows：`DBLENS_0.1.0_x64-setup.exe`，装在当前用户下，不需要管理员权限。首次运行如提示“未知发布者”，点“更多信息 → 仍要运行”。
- macOS：Apple 芯片用 `aarch64.dmg`，Intel 用 `x64.dmg`。首次打开如提示无法验证开发者，到“系统设置 → 隐私与安全性”点“仍要打开”。
- Linux：需要 WebKitGTK 4.1。
  - x64 的 `amd64.deb` 适用于 Ubuntu 22.04 及以上、Debian 12 及以上；`AppImage` 可直接运行，并支持自动更新。
  - `x86_64.rpm` 适用于 Fedora、RHEL/Rocky 10；RHEL/Rocky 9 没有 WebKitGTK 4.1，请用 AppImage。
  - ARM64（信创）用 `arm64.deb`。
  - 系统只有 WebKitGTK 4.0 的老版本（如麒麟 V10 SP1）请用浏览器模式。

这是预览版，安装包没有代码签名。
